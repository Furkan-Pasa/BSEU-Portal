# BŞEÜ Web Portal

Bilecik Şeyh Edebali Üniversitesi ve Bilgisayar Mühendisliği öğrencilerinin sık kullandığı bağlantılara, akademik takvime, yemek listesine ve sınav programlarına tek noktadan hızlıca ulaşabilmesi için hazırlanmış web portalıdır.

**Site Adresi:** https://furkan-pasa.github.io/BSEU-Portal/

> **Not:** Öğrenciler için bağımsız olarak geliştirilmiştir, kurum ile resmi bir bağı bulunmamaktadır.

## Özellikler

- Üniversite (BŞEÜ) ve bölüm (BM) bağlantıları için çift sekmeli arayüz
- Aylık yemek menüsü, akademik takvim ve sınav programı görüntüleme
- PWA desteği ile ana ekrana eklenebilme ve çevrimdışı (offline) çalışma

## Geliştirme

Tailwind CSS değişikliklerini derlemek için:

```bash
npm install
npm run build
```
